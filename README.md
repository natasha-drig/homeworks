# Задача №8

### Условие:
Создайте словарь с пятью парами «ключ-значение», где ключи - названия фруктов, а значения - их цвета. Выведите только те фрукты, цвет которых содержит букву 'к'.

### Временная сложность алгоритма: 
O(n), т.к. выполняется один проход по всем элементам словаря. Если оценивать алгоритм более строго, то поиск буквы в названии цвета также занимает время, поэтому сложность можно оценить как O(n × m), где m — длина строки. Так как названия цветов короткие и их длина практически не меняется, итоговая временная сложность остается O(n).
### Сложность по памяти: 
O(1), поскольку алгоритм не создает дополнительных структур данных, а использует только переменные цикла.
